# Halora website (askhalora.com)

Halora sells Noor, an AI receptionist for clinics in Dubai and the Gulf (WhatsApp, website chat, phone; Arabic + English).
Owner: Ziad. Hosted on GitHub Pages from `main` (root). Custom domain askhalora.com. Every push to main deploys in about 1–2 minutes.

## Rules
- Add, don't rewrite: never remove working features. Keep every existing `data-*` hook (`data-chat`, `data-voice`, `data-call`, `data-cd`, `data-end`).
- Batch changes into one commit per task. Test locally before pushing.
- Never put API keys, tokens or passwords in any file. Demo data must be fake (BrightSmile Dental, Glow Skin are fictional).
- No fake testimonials, reviews or logos of real companies.
- English is the main language; every homepage change must also go into `/ar/` (RTL, Arabic).
- Prices are in USD. The founding offer (25% off, ends 31 Dec 2026) lives in the offer bar and plans.

## Structure
- `index.html`, `ar/index.html`: homepages. Generated by `tools/build.py` and `tools/build_ar.py` from `tools/index.before-v4.html` / `tools/ar.before-v4.html` (the older sections: problem, extras, portal, plans, pilot, founder, FAQ). Edit those base files for lower sections; edit the build scripts for the v4 sections (night shift, specialties, ROI, comparison, ask bar; hero, modules, header and footer come from v5.py / site_header() / site_footer()).
- Rebuild everything: `python tools/build_ar.py` (it also runs build.py and pages.py: both homepages, 16 product/specialty pages, 16 'why Halora' pages and sitemap.xml).
- `product/{whatsapp,phone,growth,portal}/`, `specialties/{dental,aesthetics,physio,ivf}/`: generated by build.py.
- Arabic versions live at `ar/product/...` and `ar/specialties/...`, generated by build_ar.py with the shared `subpage()` in build.py.
- SEO (title, description, canonical, hreflang, Open Graph, JSON-LD) is written by `seo()` in build.py for every page, including the hand-made `call/`, `book/`, `glow/`, `sample/` heads. sitemap.xml is generated too.
- Explainer video: `assets/halora-explainer.mp4` (1:14) opens in a popup from any `[data-video]` link (x.js); it only downloads on click. `video_card()` in build.py makes the homepage hero preview card; `watch_btn()` makes the "Watch the demo" button on product/specialty pages; poster/thumbnail are `halora-explainer-poster.jpg` / `-thumb.jpg`, taken from the 8-second frame.
- `assets/site.css`, `assets/site.js`: base styles + chat widget, voice note mic, offer countdown. `site.js` talks to n8n webhooks on autova.app.n8n.cloud. Don't change webhook URLs.
- `assets/x.css`, `assets/x.js`: v4 layer (animations, night shift, specialties tabs, ROI, video popup, RTL fixes). Its old dark hero/intro code is dormant.
- v5 "The Pulse" (light clinic look): `tools/v5.py` (clay icons, UI mock-ups, hero, modules section, EN/AR strings), `assets/v5.css`, `assets/v5.js` (Pulse intro once per session via sessionStorage `hlPulse`, skippable, off for reduced motion; sticky touchpoints → 8 module cards). Load order: site → x → v5.
- `tools/pages.py`: the 8 pages /how-it-works, /pricing, /for-owners, /security, /integrations, /about, /compare, /pilot in EN and AR (run by build_ar.py). /pricing and /pilot reuse the homepage plans and pilot sections, so prices live in one place.
- Other pages: `call/` (book a call), `book/` (patient booking demo), `glow/` (skin clinic demo), `sample/` (sample clinic website).
